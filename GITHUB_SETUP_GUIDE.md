# GitHub Setup Guide (beginner friendly)

A GitHub *profile README* works only when the repository has **exactly the same name as your username**: `sridharvpr7`.

## 1. Create the special repository

1. Sign in to GitHub → click **+** (top right) → **New repository**.
2. **Repository name:** `sridharvpr7` (GitHub will show a note that this is a special repository).
3. Set it to **Public**.
4. Do **not** tick "Add a README" (you already have one). Click **Create repository**.

## 2. Prepare the files

1. Unzip `sridharvpr7-github-profile-complete.zip`.
2. Open a terminal inside the unzipped folder.
3. Run `node -v` (needs Node 16+; install from nodejs.org if missing).
4. Run `npm run validate` and `npm run generate`.

## 3. Check it locally

Open `README.md` in VS Code and press `Ctrl+Shift+V` (preview). The banner should appear at the top.

Next: follow **UPLOAD_GUIDE.md** to push the files.
